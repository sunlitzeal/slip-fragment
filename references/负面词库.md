# 负面提示词库（8 层）

> 按黄金模板顺序分 8 组，以"；"分隔粘贴。输出长度受限时，优先保留 ①②④⑦ 四层（时间戳、运镜、卡通CG、AI瑕疵）。

## ① 时间与界面（必带）

时间戳，日期文字，年月日时分秒，时间数字水印，监控播放器界面，菜单栏，进度条

## ② 运镜剪辑（必带）

镜头移动，推拉摇移，变焦，多机位切换，分屏，转场，慢动作，升格慢放

## ③ 画质风格

高清锐利画质，电影感调色，高饱和鲜艳色彩，镜头光晕

## ④ 卡通CG（必带）

卡通，动漫，3D 渲染，CG 感

## ⑤ 安全（必带，防血腥审核）

血迹，伤口，流血，受伤特写，痛苦扭曲表情，昏迷不起

## ⑥ 摆拍感

摆拍感，表演痕迹，人物看向镜头

## ⑦ AI瑕疵（必带）

人物变形，肢体扭曲，多余手指，面部畸变，手脚消失

## ⑧ 文字水印（必带）

画面乱码文字，水印

## 条件化增补表

| 场景/要求 | 追加负面词 |
|---|---|
| 用户要求画面无时间信息 | ①全量 + ②媒体包装（新闻标题，字幕条，台标，logo） |
| 面粉/粉尘场景 | 爆炸火光，浓烟 |
| 热汤/热油场景 | 烧伤，火苗，蒸汽爆炸 |
| 腾空/翻转等高难摔法 | 肢体扭曲（强化），多余肢体 |
| 水盆/水桶大水量场景 | 巨浪，洪水 |
| 商店/有招牌场景 | 乱码招牌文字，乱码店铺名 |
| 用户要求正向补充画质词 | ③全量 + 油画，插画风格 |
