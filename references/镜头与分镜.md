# 镜头语言与分镜模板（即梦 Seedance / 豆包）

> 来源于 Seedance 2.0 提示词方法论与滑倒类实测经验。滑倒类默认固定机位、无运镜；以下镜头语言仅在源视频确实存在运镜、或用户主动要求时使用。

## 铁律：不与"静止"冲突

同一段提示词里既写"全程镜头静止无运镜"又写"推近/环绕"= 指令冲突，必崩。要运镜就删掉静止句，要静止就全篇不出现运镜词。

## 即梦（Seedance 2.0）要点

- 输出时长 4-15 秒；上传素材不超过 12 个文件、禁止真实人脸照片
- @ 引用系统：给每个素材指定角色——@首帧图（画面起点）、@人物（长相着装）、@运镜、@特效、@音频
- 超 8 秒用时间段分写，每段 = 动作 + 镜头 + 音频

### 时间段分写模板（10-15 秒连锁滑倒）

```text
0-3秒 【动作】{人物}在{位置}{正在做的事}，脚下突然打滑，身体开始失衡
      【镜头】固定俯拍，机位不动
      【音频】环境嘈杂人声、餐具碰撞声
3-8秒 【动作】{摔法完整描述}，{道具连锁：盆飞出/货架散落/水花泼溅}
      【镜头】同机位不动
      【音频】物体落地哐当巨响、惊呼声
8-13秒 【动作】{落地后：撑地缓神/翻身/他人搀扶}
      【镜头】同机位不动
      【音频】环境音延续
```

### 即梦版 2 段分镜（6-8 秒单次摔倒，默认）

- 段1（0-4 秒）：打滑到落地——滑倒前动作 + 打滑瞬间 + 空中失控 + 落地
- 段2（4-7 秒）：连锁到缓神——道具连锁反应 + 落地后反应
- 两段都必须写明"机位不变"，否则第二段运镜漂移

### 参数建议

- 画幅（必填）：竖屏 9:16（后厨/窄道/走廊/单人主体）或横屏 16:9（店堂/大空间/多人互动）；用户未指定时默认竖屏 9:16 并说明，且首句、参数、封面版式三处必须一致
- 运动幅度：标准或剧烈（滑倒属大动态）
- 图生视频首帧（高难动作必用）：固定监控俯拍视角下，{人物着装}手持{道具}站在{位置}、身体微侧的瞬间，{地面}湿滑反光，画面不含天花板和灯具、曝光均匀无亮斑——首帧有灯=视频全程有灯，首帧生成后先检查顶部再喂给视频模型（可选：摊位/货架后加 1 名背景人物在忙碌，不与主体抢焦点）

## 豆包版结构

1. 视频指令：口语化整段（首句锁镜头 + 四段式正文）
2. 负面控制：负面词分层粘贴；豆包无独立负面框，"吊灯/吸顶灯/灯管/灯泡"等具象灯具词不进正文（会被当概念吸收、把灯画进顶部），防顶部灯光只靠正文内嵌句"画面中不出现天花板、灯具和过曝亮斑"+ 正文写"曝光平稳，无过曝无亮斑"
3. 封面图指令：定格"摔倒最夸张瞬间"（腾空/水花/面粉云），构图版式与画幅一致（竖屏 9:16 竖版 / 横屏 16:9 横版），顶部留标题空间，画面无文字、无天花板灯具和过曝亮斑

## 镜头语言速查（仅源视频有运镜时替换"静止"句）

| 意图 | 写法 |
|---|---|
| 缓慢接近 | 镜头缓慢推近 |
| 环绕展示 | 镜头绕人物缓慢环绕 |
| 冲击感 | 快速推近 / 希区柯克变焦 |
| 追赶跟拍 | 手持跟拍，轻微晃动 |
| 环境交代 | 广角固定全景 |

## 常见错误清单

- 引用含糊："那个人""那个盆"→ 必须具体指代（穿蓝短袖的小伙/白色塑料盆）
- 指令冲突：同段既"固定镜头"又"环绕"
- 短时长塞太多：4-5 秒塞摔倒+散落+他人搀扶 3 个事件——每秒最多 1 个大动作
- 忽略声音：可写"环境嘈杂人声、盆落地哐当巨响"（无音轨需求时省略）
- 第二段忘写"机位不变"导致镜头漂移
- 背景人物呆立/提前看镜头：群演必须"摔倒前各自忙碌、摔倒后才反应"，只写位置+着装+一个动作，不写面部长相
